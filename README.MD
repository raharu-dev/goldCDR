# goldCDR
## Description
Imagine if [Cider](https://cider.sh/) was made in GoldSRC

**THIS IS VERY WIP**

This is a early work in progress, so expect rough edges and everything working badly. So far it looks really ugly and it is recommended to not use it!

Im not really experienced in frontend development etc. so somethings might looks like heresy to experienced developers. If you think so you can put it in the issues or something (I'm willing to learn proper CSS).

## Installation
Download the zip create a directory with a number as it name and put it to the:
`%appdata%\sh.cider.dotnet\themes`
for example you can do:
`%appdata%\sh.cider.dotnet\themes\3`
